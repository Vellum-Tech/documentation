title: "Factor library"
description: "Published reference values such as prices, rates and wages, each with a source, a citation and a version history, reused across clients."
---

A factor is a published reference value: a price, a rate, a wage, an emissions
intensity. Factors carry the evidence a defensible valuation needs, a source
citation, a source tier and a version history, and the engine reads them when
it computes report figures. Curate a value once and every project that binds
it uses the same number with the same citation.

## The factor list

Open **Libraries → Factor library** to see every factor.

![The factor library list with two factors showing values, units and source tiers](/images/libraries/factors-list.jpg)

Each row shows:

| Column | Meaning |
|---|---|
| Name | The factor's name, with its category and unit beneath, a link icon when a source URL is recorded, and a version count when there is more than one |
| Value | The current numeric value |
| Unit | The unit the value is expressed in |
| Source | The source tier pill |
| Locale | The locale the value applies to, when recorded |
| Used in | How many projects apply the factor |
| Year | The period year of the current value |

Search by name, unit, locale or source tier, and filter by **Source**. The
view options button (the sliders icon) lets you group the list by source
tier, change the ordering and toggle columns.

Source tiers rank how authoritative the evidence is:

| Tier | Typical source |
|---|---|
| Govt statistic | A national statistics office or government register |
| Peer reviewed | Published academic research |
| Industry report | A sector body or commercial research report |
| Firm internal | Your firm's own analysis |
| Other | Anything else |

## The factor record

Click a row to open the factor.

![A factor record showing details, value and source cards with an Approved status](/images/libraries/factor-record.jpg)

The record is organised into cards:

- **Factor details**: name, unit, factor type (such as Monetary proxy,
  Conversion factor, Benchmark or Assumption), impact domain, category and
  priority SDGs. Click **Edit** on the card to change these in place; they
  are metadata and do not create a new version.
- **Value & source**: the current value, value type, version number, source
  tier, review status, effective period, base year, geography, and the source
  citation with a link when a URL is recorded.
- **Methodology notes**: free text on how the factor is derived, caveats and
  refresh cadence.
- **Version history**: every version with its effective period, value, who
  changed it and the change note.
- **Usage**: the projects that apply this factor, with the client, the
  activity, the version each valuation pinned and the applied value.

### Factor status

The pill next to the factor's name is its status. Click it to change status
directly.

![The factor status menu open showing Draft, In review, Approved, Deprecated and Archived](/images/libraries/factor-status-menu.jpg)

| Status | Meaning |
|---|---|
| Draft | Being drafted; not yet vetted |
| In review | Submitted for checking |
| Approved | Vetted and ready to use |
| Deprecated | Still visible, but new work should not bind it |
| Archived | Retired from use |

Each version also carries its own review status (Candidate, Needs source, In
review, Approved, Rejected or Superseded), which tracks the evidence check
for that specific value.

## Create a factor

<Note>
Creating and editing factors is staff only. The **New factor** button does
not appear for client organisation members.
</Note>

<Steps>
  <Step title="Start a new factor">
    In **Libraries → Factor library**, click **New factor**.
  </Step>
  <Step title="Define the factor">
    Give it a name and, if you wish, a description, factor type, impact
    domain, category, status and priority SDGs.

    ![The new factor form with the definition section filled in](/images/libraries/factor-new-form.jpg)
  </Step>
  <Step title="Enter the current value">
    Enter the value and pick its unit from the unit registry. You can also
    set the value type, currency, base year, period year and geography.
  </Step>
  <Step title="Cite the source">
    Enter the source citation (required), a source URL, the source tier and
    the review status. A factor without a citation cannot be saved: the
    citation is what makes the value defensible in a report.
  </Step>
  <Step title="Save">
    Click **Save factor**. The factor opens on its own record as version 1.
  </Step>
</Steps>

## Versioning: new values never overwrite old ones

Editing the **Value & source** card (or using **Edit** from the factor's
record) records a new version rather than changing the old one. Add a change
note so the history explains itself.

This is deliberate: a valuation pins the factor version it used, so a report
produced last year keeps citing last year's value even after you publish this
year's update. The version history shows every value the factor has ever
held, and the usage card shows which version each project is on.

## Where factors appear in projects

In a project's Workbench, a formula's operands are bound to factors. When the
engine computes a valuation line, it resolves each bound operand to the
factor version current at the time, records it, and the report's figures
trace back to the factor's citation. See
[Workbench](/projects/workbench).
