An organisation is a client you measure impact for: a charity, corporate, government body, or any other entity your practice works with. Every project, goal, contact, and uploaded document in Vellum belongs to an organisation, so this list is usually where a piece of work starts.

Open **Organisations** in the sidebar to see every organisation on file.

![The Organisations page showing four organisations as cards in a grid](/images/organisations/list-grid.jpg)

## The list page

The header shows how many organisations are in view. When a search or filter narrows the list, the count updates to match what is on screen.

Use the toolbar to find the organisation you need:

- **Search organisations…** matches names, legal names, sectors, and jurisdictions.
- The **Status**, **Sector**, and **Type** filter chips narrow the list to the values you pick. Sector options come from the sectors already on your organisations.
- The view toggle at the right end of the toolbar switches between the card grid and the list view.

### Card grid and list view

The card grid shows each organisation with its sector, audience tags, project count, and lifetime impact value. The list view shows the same organisations as rows with sortable columns.

![The Organisations page in list view with status, projects, and impact value columns](/images/organisations/list-view.jpg)

| Column | What it shows |
| --- | --- |
| Name | The organisation, with its sector underneath |
| Status | The organisation's standing with your practice |
| Audiences | Who the organisation reports its impact to |
| Primary contact | The main contact at the organisation |
| Projects | How many projects are on file |
| Impact value | Lifetime impact value measured across the organisation's projects |

Two more columns, **Type** and **Sector**, are available but hidden by default. Open the view options panel (the icon to the right of the view toggle) to show them, change sorting, or group rows.

## Statuses

Each organisation carries one status, shown as a coloured pill.

| Status | What it means |
| --- | --- |
| Prospect | You are in early conversations; no engagement is signed yet |
| Active client | A current client your practice is working with |
| Self-serve | The organisation runs its own measurement in Vellum |
| Archived | No longer active; hidden from the list by default |

Archived organisations stay out of the list until you click **Show archived**. You archive and unarchive from the organisation record or the row menu; see [Archive and trash](/organisations/archive-and-trash).

## Create an organisation

<Note>
You need a staff role to create organisations. The **New organisation** button and the **Trash** link do not appear for client members.
</Note>

<Steps>
  <Step title="Click New organisation">
    The button is at the top right of the Organisations page.
  </Step>
  <Step title="Fill in the essentials">
    Only **Name** is required. You can also set **Legal name**, **Type**, **Status**, **Sector**, and **Website** now, and fill in everything else on the record later.

    ![The New organisation dialog with name, legal name, type, status, sector, and website fields](/images/organisations/new-dialog.jpg)

    If the name or website looks like an organisation that already exists, a warning lists the possible matches so you can open one instead of creating a duplicate. It never blocks you; you can still create the new record.
  </Step>
  <Step title="Click Create organisation">
    The organisation appears in the list, ready to open.
  </Step>
</Steps>

## Trash

The **Trash** link at the top of the page opens the staff-only trash list, where organisations that were moved to trash can be restored. See [Archive and trash](/organisations/archive-and-trash).
