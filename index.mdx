## How Vellum works

<Steps>
  <Step title="Build in the sandbox">
    Use the Vellum UI to craft prompts or design multi-step workflows using the visual builder. Add test scenarios to validate behavior across different inputs.
  </Step>
  <Step title="Evaluate before shipping">
    Run your application against test suites with quantitative metrics. Compare versions side-by-side before promoting any change to production.
  </Step>
  <Step title="Deploy with one click">
    Push a versioned release to any environment. Vellum exposes a stable API endpoint — your application code never needs to change when you update a prompt or workflow.
  </Step>
  <Step title="Monitor in production">
    Track every execution. Review inputs, outputs, latency, cost, and quality scores in the Vellum dashboard. Configure online evaluations to run automatically on live traffic.
  </Step>
</Steps>
