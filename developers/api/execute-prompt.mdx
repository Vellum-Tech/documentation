The Execute Prompt endpoint lets you run a deployed prompt against any supported LLM and retrieve the generated output. You reference your deployment by name or UUID, supply values for all declared input variables, and optionally request extra metadata such as token usage and cost. Use the streaming variant when you want to display tokens incrementally in your UI.

## Endpoint

```
POST https://api.vellum.ai/v1/execute-prompt
```

## Authentication

Every request must include your Vellum API key as a request header.

| Header | Value |
|---|---|
| `X-API-Key` | `YOUR_API_KEY` |

---

## Request Body

<ParamField body="prompt_deployment_name" type="string" required>
  The unique name of the prompt deployment to execute. Required when `prompt_deployment_id` is not provided.
</ParamField>

<ParamField body="prompt_deployment_id" type="string">
  The UUID of the prompt deployment to execute. Required when `prompt_deployment_name` is not provided. Provide either the name or the ID — not both.
</ParamField>

<ParamField body="release_tag" type="string">
  The release tag that identifies which version of the deployment to run. Defaults to `LATEST` when omitted.
</ParamField>

<ParamField body="inputs" type="array" required>
  An array of input variable objects that are interpolated into the prompt template. Each object must include:

  | Field | Type | Description |
  |---|---|---|
  | `name` | string | The variable name as declared in the prompt template. |
  | `value` | string \| number \| object | The value to substitute for this variable. |
  | `type` | string | One of `STRING`, `NUMBER`, `JSON`, or `CHAT_HISTORY`. |
</ParamField>

<ParamField body="expand_meta" type="object">
  Set any of the following boolean fields to `true` to include additional metadata in the response.

  ```json
  {
    "usage": true,
    "cost": true
  }
  ```

  | Field | Type | Description |
  |---|---|---|
  | `usage` | boolean | Include token usage counts in the response. |
  | `cost` | boolean | Include the estimated cost for this execution. |
</ParamField>

---

## Response Fields

<ResponseField name="outputs" type="array">
  An array of output objects produced by the prompt. Each object contains:

  | Field | Type | Description |
  |---|---|---|
  | `name` | string | The output variable name. |
  | `value` | string \| object | The generated value from the LLM. |
  | `type` | string | The output type: `STRING`, `NUMBER`, `JSON`, or `CHAT_HISTORY`. |
</ResponseField>

<ResponseField name="meta" type="object">
  Present only when `expand_meta` was set in the request. Contains:

  | Field | Type | Description |
  |---|---|---|
  | `usage.prompt_tokens` | number | Number of tokens in the prompt. |
  | `usage.completion_tokens` | number | Number of tokens in the completion. |
  | `usage.total_tokens` | number | Total tokens consumed. |
  | `cost` | number | Estimated cost of this execution in USD. |
</ResponseField>

<ResponseField name="execution_id" type="string">
  A unique identifier for this execution. Use this value when submitting feedback or actuals via the `/v1/submit-completion-actuals` endpoint.
</ResponseField>

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.vellum.ai/v1/execute-prompt \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt_deployment_name": "my-prompt-deployment",
    "release_tag": "LATEST",
    "inputs": [
      {
        "name": "topic",
        "value": "renewable energy",
        "type": "STRING"
      },
      {
        "name": "max_words",
        "value": 100,
        "type": "NUMBER"
      }
    ],
    "expand_meta": {
      "usage": true,
      "cost": true
    }
  }'
```

```python Python SDK
from vellum.client import Vellum

client = Vellum(api_key="YOUR_API_KEY")

result = client.execute_prompt(
    prompt_deployment_name="my-prompt-deployment",
    release_tag="LATEST",
    inputs=[
        {"name": "topic", "value": "renewable energy", "type": "STRING"},
        {"name": "max_words", "value": 100, "type": "NUMBER"},
    ],
    expand_meta={"usage": True, "cost": True},
)

print(result.outputs[0].value)
print(result.meta)
print(result.execution_id)
```

</CodeGroup>

**Example Response**

```json
{
  "outputs": [
    {
      "name": "completion",
      "value": "Renewable energy comes from natural sources that replenish faster than they are consumed...",
      "type": "STRING"

  ],

    "usage": {
      "prompt_tokens": 48,
      "completion_tokens": 112,
      "total_tokens": 160
    },
    "cost": 0.00024
  },
  "execution_id": "exec_01hxyz1234abcdef"
}
```

## Streaming Variant

```
POST https://api.vellum.ai/v1/execute-prompt-stream
```

The streaming endpoint accepts the same request body as `/v1/execute-prompt` but returns a [server-sent events (SSE)](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) stream. Each event carries a partial token delta as the LLM generates the completion, letting you display output to users incrementally without waiting for the full response.

```python
for chunk in client.execute_prompt_stream(
    prompt_deployment_name="my-prompt-deployment",
    inputs=[{"name": "topic", "value": "renewable energy", "type": "STRING"}],
):
    print(chunk.delta, end="", flush=True)
```

## Error Codes

| HTTP Status | Code | Description |
|---|---|---|
| `400` | Bad Request | One or more input variables are missing, mistyped, or the request body is malformed. |
| `401` | Unauthorized | The `X-API-Key` header is missing or invalid. |
| `404` | Not Found | No prompt deployment was found matching the provided name or ID. |
| `429` | Too Many Requests | You have exceeded the rate limit for this endpoint. Retry after the duration indicated in the `Retry-After` header. |
| `500` | Internal Server Error | An unexpected error occurred on the Vellum side. Contact support if the issue persists. |
