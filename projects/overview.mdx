A project is one piece of impact-measurement work for an organisation: a single engagement, covering a single reporting period, that ends in a report. Everything about the engagement lives on the project: its evidence, its model, its calculation and the report itself. An organisation can have any number of projects.

Open **Projects** in the sidebar to see every project you have access to.

![The projects list showing two projects with their organisation, stage, period and total value](/images/projects/projects-list.jpg)

## The projects list

The header counts the projects on screen, so when a search or filter is active it reads as a count of the matches. Each row shows:

| Column | What it shows |
| --- | --- |
| Project | The project's title |
| Organisation | The organisation the project belongs to |
| Stage | Where the project is in its lifecycle |
| Report type | The kind of report the project produces |
| Period | The reporting period the project covers |
| Total value | The total impact value the project reports for the period |

Along the toolbar you can search projects, filter by **Stage** or **Report type**, and switch between the list and a card grid. The view options button (the sliders icon at the right of the toolbar) controls grouping, ordering and which columns are displayed.

## Grouping the list

In the view options panel, set **Grouping** to **Stage** or **Report type** to bucket the list into collapsible sections. Sections follow the lifecycle order rather than sorting alphabetically, so an overview of the pipeline reads top to bottom.

![The projects list grouped by stage, with a section per lifecycle stage](/images/projects/projects-grouped.jpg)

## The ten stages

A project moves through ten stages, from first conversation to published report. The stage is a label you set yourself: it signals where the work is up to, and nothing is locked or hidden by moving between stages.

| Stage | What it signals |
| --- | --- |
| Discovery | Early scoping: learning what the organisation does and what it wants to show |
| Research | Investigating the outcomes, evidence and measurement approach |
| Proposal | The engagement is scoped and offered, awaiting agreement |
| Engaged | The engagement is agreed and the work is underway |
| Data collection | Evidence and data are being gathered from the organisation |
| Modelling | The model is being built: activities, beneficiaries and outcomes |
| Calculation | Outcomes are being valued and the numbers computed |
| Drafting | The report is being written |
| Review | The draft is being checked before it goes out |
| Published | The report has been published |

You change the stage from the project record's header. See [The project record](/projects/project-record).

## Create a project

<Steps>
  <Step title="Click New project">
    On the **Projects** page, click **New project**.
  </Step>
  <Step title="Choose the organisation">
    A project always belongs to an organisation, chosen from your existing records. If the organisation is not there yet, create it first: see [Organisations](/organisations/overview).
  </Step>
  <Step title="Name it and set the period">
    Give the project a title. The reporting period defaults to the current Australian financial year (1 July to 30 June); adjust the start and end dates if the engagement covers a different span.
  </Step>
  <Step title="Create it">
    Click **Create project**. The project starts in the Discovery stage and opens on its record, where you can refine everything else.
  </Step>
</Steps>

![The New project dialog asking for an organisation, a title and a reporting period](/images/projects/new-project-dialog.jpg)

<Note>
Deleting a project is permanent and only its owner or Vellum staff can do it. A project that already has calculation data cannot be deleted.
</Note>

If your firm has no projects yet, the page shows an empty state with a **New project** button to create the first one.
