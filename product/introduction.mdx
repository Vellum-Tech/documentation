Vellum is an end-to-end platform for AI product development. It gives technical and non-technical team members a shared workspace to build LLM-powered applications, measure their quality rigorously, deploy them at scale, and observe them in production — all without stitching together a dozen different tools.

## Who Vellum is for

Vellum is built for teams that ship AI-powered products. It bridges the gap between the engineers who integrate LLMs and the subject-matter experts who know what good output looks like.

**Developers** get a full API and SDKs (Python, TypeScript, Go), version-controlled deployments, and integrations with existing CI/CD pipelines.

**Product teams and domain experts** get a low-code interface for editing prompts, curating test cases, labeling outputs, and approving releases — without writing code.

**Teams together** can collaborate in shared workspaces where changes in the UI sync with code and vice versa.

## Core concepts at a glance

| Concept | What it is |
|---|---|
| **Prompt Sandbox** | Interactive editor for designing and testing prompts against multiple LLM providers |
| **Workflow** | A visual graph of nodes — LLM calls, code, search, conditionals — that defines an AI application |
| **Deployment** | A versioned, API-accessible release of a Prompt or Workflow |
| **Environment** | An isolated context (e.g. Dev, Staging, Production) with its own API keys and release history |
| **Test Suite** | A collection of input/expected-output pairs used to evaluate a Prompt or Workflow |
| **Metric** | A scoring function that grades model outputs quantitatively or qualitatively |
| **Document Index** | A searchable vector store for powering RAG pipelines |

<Note>
  Vellum supports both a cloud-hosted offering at `app.vellum.ai` and a self-hosted VPC deployment. Most features described in this documentation apply to both. Where differences exist, they are noted explicitly.
</Note>
