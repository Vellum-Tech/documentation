This guide walks you through the fastest path from zero to a live Vellum deployment. By the end, you will have a prompt deployed to an API endpoint and be able to call it from your application.

## Prerequisites

- A Vellum account (sign up free at [app.vellum.ai](https://app.vellum.ai))
- Python 3.8+ or Node.js 18+ if you want to follow the SDK steps

<Steps>
  <Step title="Create an account and workspace">
    Go to [app.vellum.ai](https://app.vellum.ai) and sign up. After onboarding, you land in your default **workspace** — a shared environment where your team's prompts, workflows, and deployments live.

    <Tip>If your team already has a Vellum workspace, ask an admin to invite you via **Settings → Team Members**.</Tip>
  </Step>

  <Step title="Get your API key">
    Navigate to **Settings → API Keys** and create a new key. Copy it — you will use it in the steps below.

    Store your key as an environment variable so you never hard-code it:

    ```bash
    export VELLUM_API_KEY="your-api-key-here"
    ```
  </Step>

  <Step title="Create a prompt in the sandbox">
    1. In the sidebar, click **Prompts** → **New Prompt Sandbox**.
    2. Give your prompt a name (e.g. "Customer Support Classifier").
    3. Choose a model provider and model (e.g. OpenAI GPT-4o).
    4. Write your system prompt and add a `{{query}}` input variable.
    5. Click **Run** to test it against a sample input in the right panel.

    Iterate until you are happy with the output, then click **Deploy**.
  </Step>

  <Step title="Deploy the prompt">
    In the deploy dialog:
    - Give your deployment a name (e.g. `customer-support-classifier`).
    - Select the **Development** environment.
    - Click **Deploy**.

    Vellum creates a stable API endpoint backed by this prompt version. Future updates create new releases — your endpoint URL never changes.
  </Step>

  <Step title="Call the deployment from code">
    Install the Vellum SDK:

    <CodeGroup>
    ```bash pip
    pip install vellum-ai
    ```
    ```bash npm
    npm install vellum-ai
    ```
    </CodeGroup>

    Execute your deployed prompt:

    <CodeGroup>
    ```python Python
    import vellum

    client = vellum.Vellum(api_key="YOUR_API_KEY")

    result = client.execute_prompt(
        prompt_deployment_name="customer-support-classifier",
        inputs=[
            vellum.PromptDeploymentInputRequest(
                name="query",
                value="How do I reset my password?",
                type="STRING",
            )
        ],
    )

    print(result.outputs[0].value)
    # → "Account & Login"
    ```
    ```typescript TypeScript
    import Vellum from "vellum-ai";

    const client = new Vellum({ apiKey: "YOUR_API_KEY" });

    const result = await client.executePrompt({
      promptDeploymentName: "customer-support-classifier",
      inputs: [
        {
          name: "query",
          value: "How do I reset my password?",
          type: "STRING",
        },
      ],
    });

    console.log(result.outputs[0].value);
    // → "Account & Login"
    ```
    </CodeGroup>
  </Step>
</Steps>
